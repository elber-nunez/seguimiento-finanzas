# Conexión con Firebase

La aplicación sigue funcionando con almacenamiento local. La siguiente etapa conectará:

- Firebase Authentication con Google.
- Cloud Firestore para sincronizar los datos.
- Acceso limitado a los correos de Elber y Mayra.

## Datos necesarios

1. Configuración web de Firebase (`firebaseConfig`).
2. Correo de Google de Elber.
3. Correo de Google de Mayra.

No se requiere ninguna contraseña.
